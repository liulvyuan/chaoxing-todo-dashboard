# 使用说明

## 一、怎么用

1. 装好 Node.js 18+（不需要 npm install，本项目零依赖）
2. 复制 `config.example.json` 为 `config.json`，填入学习通账号密码
3. 双击 `start.bat`（Windows）或执行 `node server.js`
4. 浏览器会自动打开 http://127.0.0.1:7788，之后每 30 分钟自动抓一次，按 F5 就是最新

其他入口：

- `refresh.bat` / `node study-tracker.js`：只抓一次，然后打开 `report.html` 静态报告
- 直接双击 `report.html`：看最近一次结果，不抓取
- `node study-tracker.js --render-only`：用现有 `data.json` 重建看板，不重新抓取

重复点 `start.bat` 不会报错，服务已在跑时只会再打开一次浏览器。

## 二、看什么

- 待交作业：未交的作业，带截止时间、成绩
- 待考考试：未参加的考试，带考试时间
- 课堂活动 / 随堂练习：课程“任务”页里进行中的活动（分组任务、主题讨论、问卷、随堂练习）

不显示讨论区话题。如需恢复，在 `config.json` 里加 `"showDiscussion": true`。

看板顶部可以按“从某年某月起开始截止的任务”筛选，选择会写到 `filter.json`，刷新不丢。

## 三、文件

| 文件 | 作用 |
| --- | --- |
| `study-tracker.js` | 主程序：登录、遍历课程、抓取、解析、输出 |
| `lib/chaoxing.js` | 接口层：登录加密、课程列表、票据参数、作业/考试/活动 |
| `render.js` | 生成 HTML 看板 |
| `server.js` | 本地看板服务，监听 127.0.0.1:7788 |
| `data.json` | 最近一次抓取的原始数据（已被 gitignore） |

## 四、说明

程序只读取页面上的待办状态，不提交作业、不参加考试、不发讨论。作业与考试状态为空但能点“查看”的，按已提交处理。单次全量抓取约 20 秒。
